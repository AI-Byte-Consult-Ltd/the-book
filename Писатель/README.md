# Проект «Писатель»

Отдельный рабочий проект автора Александра Лунина (AI Byte Consult Ltd., проект NICS AI Ecosystem) для работы над романом **«Появление / The Appearance»** (серия «Terra Incognita», книга первая). Модель проекта: Claude Opus 5.5.

Автор общается по-русски. Отвечать по-русски, коротко и по делу.

## Что читать первым (в таком порядке)

1. `«ПОЯВЛЕНИЕ» — ОГЛАВЛЕНИЕ (полная переработка).md` - главный рабочий документ: формат книги, статус, план Части первой, главная нить, Части вторая и третья, неиспользованные идеи, открытые сюжетные узлы, выходные данные, карта сюжета, полный список действующих лиц.
2. `Писатель/ПРАВИЛА.md` - правила работы (этот файл рядом).
3. `English/glossary.md` - глоссарий имён, терминов и приёмов перевода (русский -> английский).
4. Готовые главы лежат в корне репозитория (`Глава ...`, `Видение ...`, `Явь ...`). Английские переводы в `English/`.

## Состояние на сейчас

- **Часть первая готова целиком в русском тексте**: 59 единиц (Глава I - XXXIX, Видение I - VIII, Явь Пролог + I - XI) - переведены на английский, всё в `main`.
- **Части вторая и третья существуют только как план** в оглавлении (раздел «ЧАСТЬ ВТОРАЯ. ХРАНИТЕЛИ ПОРОГА», «ЧАСТЬ ТРЕТЬЯ. ИСТИННОЕ ВРЕМЯ»). Текста нет.
- **Издательская сборка готова** (см. `epub/` и `paperback/`):
  - `epub/Появление.epub` - русская электронная книга (обложка `epub/cover.jpg`, «Об авторе» в конце).
  - `epub/The Appearance.epub` - английская электронная книга (обложка `epub/cover_en.jpg`).
  - `epub/The Appearance.docx|.doc` - единый английский Word для KDP (электронная версия).
  - `paperback/` - английская печатная версия в двух томах (Том I: Chapter I - XXII, 425 стр.; Том II: Chapter XXIII - Reality XI, 452 стр.), DOCX и PDF, формат 6x9.
  - Скрипты: `epub/build_ru.py`, `epub/build_en.py`, `epub/build_docx_en.py`, `paperback/build_print_en.py`.

- **Опубликовано на Amazon** (печатное издание): https://www.amazon.com/dp/B0HMJSPC44 . Верный ISBN-13: 979-8161258644 (подтвердил автор 22.11.2026).
