# Правила работы над романом

## Главное
- **Главы пишутся только по прямой команде автора, не проактивно.** Уже написанное не переделывать задним числом без явного запроса.
- Перед каждой новой главой перечитать в оглавлении: главную нить Части первой, открытые сюжетные узлы, нужную линию действующих лиц, заделы (например, «Заделы из гл. XIX»), «Неиспользованные идеи».
- Сквозная нумерация глав без сброса на границах частей; видения и «Явь» идут со своими названиями.
- После каждой главы: короткий отчёт автору по-русски, со списком несостыковок в исходнике, если они найдены.
- Не фантазировать за автора там, где в оглавлении сказано «толкование открыто» или «сознательно не закрываем». Спрашивать.

## Перевод на английский (когда автор просит)
- Профессиональный литературный перевод по одной главе, строго в порядке оглавления; файл сохранять в `English/`.
- В английском тексте **нет длинного тире «—»**, только дефис «-».
- Игру слов транслитерировать и пояснять; турецкие фразы оставлять как есть (Misafir, Su! Buz gibi su!, Sandık, Dönüş); «чати» = Vizier; «Явь/Навь» = Yav/Nav; разделы линии Явь называть «Reality N. ...».
- Египетские имена по глоссарию (Ptahhotep, Senusret, Khemu, Nanakhat, Iti и др.).
- Каждую главу добавлять в `English/glossary.md`: вставлять новый раздел `## ...` перед `## Left untranslated`.

## Сборка книг
- Русская: `python3 epub/build_ru.py`; английская электронная: `python3 epub/build_en.py`; Word для KDP: `python3 epub/build_docx_en.py`; печатные тома: `python3 paperback/build_print_en.py`.
- Порядок глав берётся из таблицы Части первой в оглавлении (строки со значком ✅). Новая глава попадает в книгу только по команде автора «добавь в книгу».
- Проверка EPUB: EPUBCheck 5.1.0 (Java не принимает имена файлов не-ASCII - проверять копию с ASCII-именем).
- Метаданные: автор Александр Лунин / Alexander Lunin; серия «Terra Incognita», книга 1; ISBN 979-8176203813; права «Copyright © 2020 - 2026 Alexander Lunin».

## Git
- Рабочая ветка: `claude/brave-hopper-9k41s0`. Коммит -> `git push -f -q -u origin claude/brave-hopper-9k41s0` -> Pull Request в `main` (`AI-Byte-Consult-Ltd/the-book`) -> squash-слияние -> `git fetch origin main && git reset --hard origin/main && git push -f origin claude/brave-hopper-9k41s0`.
- Публиковать в `main` после каждой главы.
